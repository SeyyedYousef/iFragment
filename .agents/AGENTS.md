# Workspace Rules - Hallmark Integration

This file defines the project-scoped rules for the `iFragment` workspace.

## 🚫 Anti-AI-Slop UI/UX Constraints (Hallmark Integration)

Whenever creating or modifying any user interface (UI) components or pages, you MUST adhere to the Hallmark design principles:

1. **No Purple Gradient Heroes**: Pick a single anchor color and avoid multi-color gradient fills behind hero/page text.
2. **Typography Contrast**: Do not use the same font (like Inter or Roboto) for both headers and body. Use distinct pairings.
3. **No 3-Column Feature Grids**: Avoid the repetitive 3-column layout (icon + header + short paragraph). Use asymmetric column sizes, Bento grids, or lists.
4. **No Card-in-Card Nesting**: Pick one container layer and remove redundant nested borders.
5. **No Text Gradient Fills**: Headings must use solid typography, not gradient text fills (e.g. blue-to-pink gradients).
6. **No Side-Stripe Cards**: Avoid cards with thick left-border accent stripes.
7. **No Pure Black/White**: Use slightly tinted neutral colors (e.g., `#0f1014`, `#1c1c1c`) instead of `#000000` or `#ffffff` to give the UI a premium feel.
8. **No Italic Headers**: Display headings must always be roman (upright). Do not use italicized words inside titles.
9. **No Floating-Orb Backgrounds**: Avoid placing blurry decorative ambient circles behind page sections.
